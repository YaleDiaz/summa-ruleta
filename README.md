# 🎡 SUMMA — Sorteo Élite

Ruleta animada para hacer los sorteos y giveaways de **SUMMA Clothes** en vivo o en Reels.

- Ruleta giratoria en negro, morado y dorado
- Funciona en el navegador, también desde el celular
- Un solo archivo `index.html` (HTML + CSS + JavaScript)

## ▶️ Cómo usarla
Abre `index.html` en el navegador y gira la ruleta.

Ver también: [👕 Sitio de SUMMA Clothes](https://github.com/YaleDiaz/summa-clothes)
